# 仙魔雙修 fairymagic

中式修仙 × 西式魔法學院嘅自創武學網頁遊戲（單一 `index.html`，無需 build）。

- 仙門：風木水火土・陰陽；學院：風木水火土・光暗
- 融合異屬性：雷、重力、時間、空間、召喚、毒、影、惡魔、燃血、長生、變身、幻境、分身
- 創招爐：屬性 × 形態（劍、掌、陣、罩、咒、訣）自創武學，試煉塔回合制戰鬥
- 進度存喺瀏覽器 localStorage（key: `xianmo-v1`）

## 檔案
- `index.html`：成個遊戲（favicon 內嵌）
- `og.png`：社交分享圖 1200×630

部署後，記得將 `og:image` 改成完整網址（例如 `https://你的網域/og.png`）。
